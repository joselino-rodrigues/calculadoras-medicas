# Calculadoras Médicas

Coleção de calculadoras médicas desenvolvidas para auxiliar em cálculos clínicos, com fórmulas documentadas, referências bibliográficas e testes de validação.

## 🎯 Objetivo

Desenvolver ferramentas simples, transparentes e acessíveis para o cálculo de parâmetros utilizados na área da saúde, priorizando a clareza das fórmulas, a confiabilidade dos resultados e a facilidade de uso.

## ✨ Características

- Fórmulas matemáticas documentadas.
- Referências científicas para os métodos utilizados.
- Validação das unidades e dos dados de entrada.
- Testes para verificar os resultados.
- Código aberto para estudo, colaboração e melhorias.

## 🚀 Como utilizar

As instruções de instalação e utilização serão adicionadas conforme as calculadoras forem implementadas.

## ⚠️ Aviso importante

Este projeto tem finalidade educacional e informativa. Os resultados não substituem a avaliação de profissionais de saúde, o julgamento clínico ou os protocolos institucionais.

Antes de utilizar qualquer resultado em decisões clínicas, verifique a fórmula empregada, suas limitações, as unidades utilizadas e as referências científicas correspondentes.

## 🤝 Contribuições

Contribuições são bem-vindas! Sugestões, correções, relatos de problemas e novas calculadoras podem ajudar a melhorar o projeto.

Ao propor uma nova calculadora, procure incluir:

- Fórmula utilizada e descrição das variáveis.
- Unidades de medida.
- Referências científicas.
- Testes com resultados conhecidos.
- Limitações e condições de uso.
